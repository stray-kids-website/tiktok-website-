TikTok Website
📌 About the Project
TikTok is a popular social media platform that allows users to create, watch, edit, and share short-form videos. Users can explore entertaining content, follow their favorite creators, interact with videos, and discover new trends.

This project aims to create a website inspired by TikTok, featuring a simple and user-friendly interface for browsing and sharing video content.

✨ Features
Home Feed: Browse and watch short videos.
Discover: Explore trending videos, hashtags, and creators.
User Profiles: View creator information and uploaded videos.
Likes and Comments: Interact with video content.
Follow System: Follow creators and see their content.
Search: Find videos, users, and hashtags.
Responsive Design: Access the website on desktop, tablet, and mobile devices.
